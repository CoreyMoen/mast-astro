The browser ships more framework than most frameworks. Details elements that disclose, dialogs that trap focus, scroll containers that snap, color functions that theme — features that used to need libraries are now a property away.

## Use the platform first

Every native feature you lean on is code you don't ship, behavior you don't maintain, and accessibility you get for free:

1. `<details>` for accordions
2. `<dialog>` for modals
3. `light-dark()` for theming
4. Scroll snap for sliders

The job of a minimal framework isn't to wrap the platform. It's to arrange it — and then get out of the way.
